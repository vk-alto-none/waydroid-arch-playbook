# 🔍 Comprehensive Waydroid Troubleshooting & Error Directory

| Error Message in Logs | Root Cause | Exact Solution |
|:---|:---|:---|
| `[gbinder] ERROR: Can't open /dev/anbox-binder: Permission denied` | `/dev/binderfs` mount point has default `0700` mode. | Run `sudo chmod 755 /dev/binderfs && sudo chmod 666 /dev/binderfs/*` and add udev rule `99-waydroid-binder.rules`. |
| `lxc-start: ERROR: Ignoring mount point "/run/xdg"` | LXC 7 forbids leading slashes in destination paths. | Patch `lxc.py` to strip leading slashes on container mount destinations (`run/xdg`). |
| `lxc-start: Failed to mount "/dev//dev/binderfs/..."` | Double `/dev/` prefix generated by string concatenation in `lxc.py`. | Patch `generate_nodes_lxc_config` in `lxc.py` to sanitize driver string. |
| `lxc-start: Script exec /dev/null ... Script exited with status 126` | LXC 7 fails trying to execute non-executable `/dev/null` as post-stop hook. | Remove `lxc.hook.post-stop = /dev/null` in `/usr/lib/waydroid/data/configs/config_3`. |
| `Failed to mount "tmpfs" onto ".../run/xdg": No such device` | `lxc.mount.entry` had `mnt_type="none"` instead of `"tmpfs"`. | Pass `mnt_type="tmpfs"` in `make_entry("tmpfs", ...)` in `lxc.py`. |
| `RuntimeError: Command failed: % mv .../config_session /var/lib/waydroid/lxc/waydroid` | `/var/lib/waydroid/lxc` directory did not exist. | Create directory `sudo mkdir -p /var/lib/waydroid/lxc/waydroid` with permissions. |
| `RuntimeError: waydroid_base.prop Not found` | Base properties file missing before container initialization. | Create `/var/lib/waydroid/waydroid_base.prop` with GBM/Mesa GPU properties. |
| `Waiting for binder Service Manager... Service Manager never appeared` | Container failed to start due to mount/permission error or binderfs mismatch. | Check `sudo waydroid log` and inspect `lxc-start` output in `/tmp/lxc_debug.log`. |
| Container constantly entering `FROZEN` state | Waydroid default suspend policy freezes container on window blur. | Set `suspend_action = none` in `waydroid.cfg` and `persist.waydroid.suspend false`. |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | Attempting to install ARM64 APK on x86_64 CPU without translation. | Install `libndk` via `waydroid_script`. |
| `Oops! An error occurred / No Internet in APKPure or Apps` | UFW firewall blocking routed forwarding (`DEFAULT_FORWARD_POLICY="DROP"`) or DNS stub issue. | Run `sudo ufw allow in on waydroid0`, enable MASQUERADE NAT, and set `waydroid prop set net.dns1 1.1.1.1`. |
| `Guest call didn't restore sp: expected 0x... actual 0x...` in `libndk_translation.so` | Tencent Anti-Cheat (`GP7Service`) obfuscated stack manipulation triggers `SIGABRT` in `libndk`. | Upgrade translation engine to Intel `libhoudini` via `waydroid_script`. |
| `CODMainActivity: exit Game Call` / `Process exited due to signal 9 (Killed)` | Activision anti-cheat hardcoded emulator check (`GetEmulatorResolutionHeight`) rejects non-GameLoop environments. | Intentional anti-cheat kill switch in CODM; play native PC Call of Duty via Steam/Proton or run supported Android titles (Free Fire, PUBG, Brawl Stars). |
